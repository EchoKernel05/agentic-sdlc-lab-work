# Issue 5: Order returns

Add `RETURNED` as an order status, allow the transition from `DELIVERED` to
`RETURNED`, and treat `RETURNED` as terminal. Cancellation must reject returned
orders.

## Open questions

- Should returns be allowed only within 30 days of delivery? Orders currently
  have no delivery date, so the 30-day window cannot be enforced until that data
  is available.
- The rebased unit suite has an existing `test_delivered_is_terminal` assertion
  requiring `DELIVERED` to have no transitions, while issue 5 requires allowing
  `DELIVERED -> RETURNED`. Which business rule should take precedence?

## Decision (human)
- DELIVERED is terminal except for returns. The issue 6 test was replaced by a stricter one stating exactly DELIVERED -> RETURNED. Reason: the business rule changed on purpose.
